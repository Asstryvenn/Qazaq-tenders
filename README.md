# Qazaq Tenders

Экономический симулятор участия МСБ в госзакупках РК: TOS-индекс, кассовый разрыв,
логистика, правовые риски и AI-консультант.

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # заполните ключи (всё опционально — без них работает демо-режим)
npm run dev                  # http://localhost:3077
```

| Переменная | Где взять | Без неё |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase → Project Settings → API | Профиль хранится в localStorage, вход/регистрация отключены |
| `OPENAI_API_KEY` (`OPENAI_MODEL`, по умолчанию `gpt-4o-mini`) | platform.openai.com/api-keys | AI-консультант отвечает «ключ не подключён» |
| `GOSZAKUP_TOKEN` | Токен OWS API от Единого оператора (goszakup.gov.kz) | Показываются 6 демо-лотов |

### Supabase

1. Создайте проект на [supabase.com](https://supabase.com).
2. SQL Editor → вставьте [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql) → Run.
   Создаются таблицы `companies` (цифровой двойник) и `chat_messages` с RLS — каждый видит только свои строки.
3. Скопируйте URL и `anon` key в `.env.local`, перезапустите `npm run dev`.
4. По умолчанию Supabase требует подтверждения почты — после регистрации придёт письмо.

## Тарифы и оплата

| План | Цена | AI-запросы | Что открывает |
|---|---|---|---|
| 🟢 FREE | 0 ₸ | 5 в день, `gpt-4o-mini` | TOS и резюме лота |
| 🔵 PRO | 2 990 ₸ / мес | 300 в месяц, `gpt-4o` | полный анализ, What-If, чеклисты, Telegram |
| 🟣 MAX | 5 990 ₸ / мес | 6 000 в месяц, `gpt-4o` + `o3-mini` | всё из PRO + генератор `.docx` |

Цены и лимиты — в [`lib/plans.ts`](lib/plans.ts), это единственный источник правды.

**Что проверяет сервер** (обойти из браузера нельзя): тариф берётся из `subscriptions`
по проверенной сессии Supabase, запросы к AI считает SQL-функция `consume_ai_query()`
(умеет только увеличивать счётчик), 429 при превышении; модель и инструменты AI
выбираются по тарифу; `.docx` собирается на сервере только для MAX; Telegram-алерты — PRO+.
AI доступен только вошедшим пользователям: лимит «по IP» для гостей обходится подменой заголовков.

**Что только в интерфейсе:** размытие разделов анализа для FREE — движок считает в браузере.

**Оплата картой (Visa / Mastercard) через CloudPayments.** Данные карты вводятся в виджете
CloudPayments и к нам не попадают. План активирует только вебхук «Pay»
(`/api/billing/cloudpayments/pay`) с проверкой подписи `Content-HMAC` (HMAC-SHA256 от тела).

1. Заключите договор с CloudPayments Kazakhstan, в кабинете возьмите Public ID и API Secret.
2. В `.env.local`: `CLOUDPAYMENTS_PUBLIC_ID`, `CLOUDPAYMENTS_API_SECRET`, `SUPABASE_SECRET_KEY`.
3. В кабинете укажите уведомление Pay → `https://<ваш-домен>/api/billing/cloudpayments/pay`.
4. Выполните миграцию `supabase/migrations/0004_billing.sql`.

Пока ключей CloudPayments нет, работает **тестовый checkout**: без полей карты, с явной пометкой,
активирует план (без `SUPABASE_SECRET_KEY` — только в памяти сервера до перезапуска).
В продакшене выставьте `PAYMENTS_TEST_MODE=off`.

## Архитектура

```
PDF/ТЗ ─► Layer 1 (AI, только извлечение) ─► TenderSpec JSON ─► Layer 2 (движок) ─► TOS / графики
                                                                     ▲
                                  AI Консультант ── tool: run_scenario ┘  (LLM не считает деньги сам)
```

- `lib/engine.ts` — детерминированный движок: Π, M_rel, посуточный CF_t, L_score, R_legal, TOS.
- `lib/kz-standards.ts` — нормы РК: обеспечение заявки 1%, исполнения 3%, неустойка 0,1%/день с лимитом 10%, КПН 20%, упрощёнка 4%.
- `lib/logistics.ts` — расстояния между 18 городами (great-circle × 1,25) и тариф фуры по км × тоннажу, с долей топлива 40%.
- `lib/tenders/source.ts` — адаптер goszakup OWS v3 GraphQL с откатом на демо-лоты.
- `lib/summary.ts` — «Түсінікті тілмен»: объяснение без терминов, строится из тех же чисел, без LLM.
- `app/api/chat/route.ts` — AI-консультант (OpenAI, tool calling): `run_scenario` вызывает движок, `get_spec_pages` цитирует ТЗ.
- `lib/profile.tsx` — сессия Supabase + профиль компании, `components/auth/*` — вход, регистрация, онбординг.

## Что оценочное, а не точное

- **Расстояния** — прямая × 1,25, а не маршрут по дорогам. Интерфейс `DistanceProvider` готов под Google/Yandex.
- **Тариф фуры, комиссия банковской гарантии (2,5% годовых, мин. 50 тыс ₸)** — средние по рынку, не закон.
- **Упрощённая декларация 4%** — базовая ставка; маслихаты могут её менять. Сверьте с действующим НК.
- **Лоты goszakup**: API отдаёт объявление (название, сумма, заказчик, срок), но не условия из PDF.
  Срок поставки, отсрочка, себестоимость, тоннаж и город для таких лотов — оценки до подключения парсинга,
  в интерфейсе они помечены «условия оценены». Имена полей GraphQL сверьте со схемой OWS по своему токену.

## Осознанные отклонения от исходных формул

1. **`marginScore` нормирована** к `TARGET_MARGIN_PCT = 20`, иначе `w1 · M_rel` при марже 15% даёт 15 из 35 баллов.
2. **`opexAllocation = 0.35`** — на один контракт относится доля накладных, а не весь месячный OPEX.
3. **Цвет по вердикту**, а не по сырому TOS — лот с кассовым разрывом не может быть зелёным.
4. **`C_bank` в два прохода**: первая симуляция находит разрыв, проценты по нему учитываются во второй; налог пересчитывается после.
